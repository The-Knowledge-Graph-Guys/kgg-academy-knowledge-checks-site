Ask the Graph

One question language for the data and for the blueprint. Load a graph, ask it what it knows, then ask it what it is. Every question here is standard SPARQL, running in your browser on an open-source engine, and would run unchanged on any standards-based triple store.

The graph

Turtle, the W3C text format for RDF. Paste your export from the Ontology Builder, open a .ttl file, or use the sample.

Starting the query engine…
What is running. SPARQL 1.1 Query (W3C Recommendation, 2013) executed by Oxigraph, an open-source RDF store compiled to WebAssembly. Nothing leaves your browser. The same queries, and the same Turtle file, work on any store that implements the standard.
  • Questions to ask a vendor: does it import and export standard Turtle? Does it answer standard SPARQL? Can we leave with our data and our blueprint intact?

Ask the data

A-Box

The facts: which things exist and what has been said about them. Click any thing in a result to see everything the graph knows about it.

Ask the blueprint

T-Box

The same language, pointed at the ontology itself. Classes and properties are triples too.

Ask both at once

A-Box + T-Box

The proof that context is a first-class citizen: one query reads a fact and the rule that permitted it.
